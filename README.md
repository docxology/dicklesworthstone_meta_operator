# Dicklesworthstone Meta-Operator

The Dicklesworthstone Meta-Operator inventories a public GitHub repository
corpus, verifies local clones against their upstream default branches, and
generates a dashboard and catalog. The tracked outputs capture historical
runs and support the research manuscript.

- [Render from the saved snapshot](docs/README.md#use-the-saved-snapshot) with Python 3.11 or newer and the locked uv environment. The saved snapshot needs no live GitHub login.

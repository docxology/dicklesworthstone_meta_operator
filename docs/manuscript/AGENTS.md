## The token protocol (RASP for numbers)

1. Change behavior → re-run the pipeline stages → re-run
   `scripts/z_generate_manuscript_variables.py`.
2. Run `uv run pytest tests/test_manuscript_variables.py -q`. It fails in the
   direction of the drift:
   - prose token the generator doesn't emit → you invented a number: delete it
     or make the artifact real;
   - generator token the prose doesn't use → stale generator: update prose or
     prune the token (both fail; fix the correspondence).
3. Never hand-edit `output/data/manuscript_variables.json` — it is a tracked
   artifact regenerated by the z-script.
4. Equations carry `{#eq:*}`, figures `{#fig:*}`, tables `{#tbl:*}`, sections
   `{#sec:*}` labels; reference them only as `[@label]`. Registries live in
   [`SYNTAX.md`](SYNTAX.md) — update them in the same commit as the formalism.

## Figure protocol

Figures are generated by `src/figures.py` (pure, deterministic, colorblind-safe
palette) via `scripts/65_generate_figures.py` into `output/figures/`. Manuscript
references them as `../../output/figures/<name>.png`. Captions are self-contained
sentences. Never edit a PNG; regenerate it.

## Status and gates

[`MANUSCRIPT_STATUS.md`](MANUSCRIPT_STATUS.md) records the live manuscript
status. Verification commands:

```bash
uv run pytest tests/test_manuscript_variables.py tests/test_figures.py -q
uv run python scripts/z_generate_manuscript_variables.py
uv run python scripts/65_generate_figures.py
```

All three must be green before any manuscript edit is complete.
